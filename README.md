Entry for the make.fun bounty **Invent a Word We Need**. `main.ts` coins one new English word — *phonnesia*, the lapse of unlocking your phone to do one thing and forgetting what it was the moment the screen lights up — and writes the word with its one-line definition (109 characters) to `/output/entry.txt`. The output is deterministic: every run writes byte-identical output, and the program gate-checks the line (1–140 characters, single line, valid UTF-8, one sentence, required concrete details present) before writing.

## Run it

```sh
node main.ts
```
